THE STORMFALL OBSERVATORY - MULTI-PAGE WEBSITE

Open index.html to view the homepage. Navigate through the site using the buttons.

This is a genuine multi-page static website. Each world has its own worlds/<name>/index.html, with separate Lore, Places, and Characters pages. Edevra has five collection pages. Events has a separate page.

Shared images and CSS live in assets/. Original Elderwild materials are preserved in elderwild/.

No content has been invented for unfinished archives.

To publish on GitHub Pages, upload the CONTENTS of this folder to the repository root. Keep the folder structure intact.
